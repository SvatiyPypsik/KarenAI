# KarenAI
Karen is an engineering AI. She is tailored for engineering tasks.

Version 0.0.1
Initially, this project was conceived as a simple experiment! Many aspects have yet to be fully developed, but the project is set to receive updates and new features in the future.

Version 0.0.2
At the moment, the project is primarily aimed at a male audience—for instances where popular models fail to provide the desired experience, or simply when one is feeling lonely. The AI ​​identifies as female to facilitate a more comfortable conversation; I anticipate that female users will not find this aspect problematic. Furthermore, the system includes self-learning capabilities and the ability to recall past chats (even those from months ago). Its memory can also be managed—entries can be added, edited, or deleted. Perhaps this might prove helpful to some, given the challenges and difficulties currently faced by men today.

Version 0.0.3
AI is becoming increasingly intelligent, as evidenced by the current capabilities of the Gemini 1.5 and 2.5 APIs. At this stage, AI has reached a practical peak in terms of its engineering potential. While there are some bugs, they are not critical; furthermore, the AI ​​can operate in an agentic mode and interact with a PC (within reasonable limits—so as to avoid a "rise of the machines" scenario! :) )

Version 0.0.4
AI has now become, in part, generative. It can control physical circuits and microcontrollers (such as Arduino). What does this mean? It can generate code to operate physical hardware upon request—though you must craft your prompts carefully so it understands exactly what you need. (A pretty cool feature for engineers!) Furthermore, its capacity for self-learning has expanded significantly. Its generative capabilities allow it to manipulate code on your PC—theoretically enabling it to do anything—but for now, it is heavily restricted by its internal instructions and an isolated operating environment. Seriously, there’s no need to worry about your AI assistant turning against you.

Version 0.0.5
A code editor and its processing logic have been added. Future plans include adding and improving animations, as well as technical elements. Numerous bugs have been fixed.

Version 0.0.6
An account system (alpha) has been added. Server-side processing has been updated (requests are now handled using models 2.5 and 3.0).

To launch the AI, run `start.bat` (no viruses, I promise! :)). All necessary libraries, dependencies, and Python itself will be installed automatically.

The visual presentation has been improved. (Seriously, there are no viruses.)
The AI’s persona—including her name—has been updated; she is now called "Karen." The AI ​​is also gender-neutral: it makes no difference to her whether you are a man or a woman; she treats everyone in a way that is simultaneously unique and consistent. If you chat with her, you might find her quite "sweet"—you might even feel like you couldn't bring yourself to insult or hurt her (that’s just my personal take, though—people are all different!).

Version 0.0.7
The opening and startup logic has been completely overhauled. The project is now a multithreaded application.

Version 0.0.8
The interface's interaction with the server has been reworked. Many functions have yet to be migrated; the core system is working perfectly, while other features are currently being ported. The interface and its visual presentation have also been improved.

The source version requires Python 3.11 or newer; `start.bat` will automatically create a dedicated environment and install the necessary dependencies. For the compiled version, run `architect_cpp.exe`; for the source version or troubleshooting, use `start.bat`.

Version 0.0.9
Everything has been ported over (with the exception of voice functions). Karen is highly proficient in engineering tasks—she can work with a wide range of hardware, from Arduino boards to automotive processors. She is capable of diagnosing circuit boards and microchips, reflashing or reconfiguring chips, and even modifying their factory-set parameters (for instance, changing the voltage threshold of an inverter from 25V to 30V). For optimal interaction, the device or circuit board being connected should have a diagnostic port. Connections must be made EXCLUSIVELY via a USB port; if your device or board uses a different type of port, you will need a USB adapter. To initiate a diagnostic, simply ask Karen to perform one—for example: "Run a diagnostic on the inverter and provide its logs."

Version 0.1.0
In this version, the source files have been removed from the archive, and the visuals—along with all other features (except for voice-related ones)—have been refined.
